## Cambio de código

Se comparte la anotación idempotente de interés entre primera entrega y entrega
duplicada. Si falla la primera anotación y vuelve a llegar el mismo mensaje,
se intenta reparar la nota sin reenviar la respuesta WhatsApp. Se conservan
los requisitos de bandera activa y teléfono autorizado. No cambia Brain,
nombres confirmados, empresa, selección de servicios ni la respuesta normal.

Se añade `tests/axira-webhook-isolated.test.mjs` al workflow de GitHub Actions.
Ejecuta el handler y los módulos existentes con NextRequest/NextResponse reales,
pero reemplaza SQL, Brain y proveedores HTTP por simulaciones en memoria.
No hereda variables de entorno ni permite solicitudes HTTP reales.

## Pendientes que bloquean la activación

1. **Aislar Preview**. Configurar `DATABASE_URL` solo para Preview y esta rama,
   usando la conexión del endpoint QA. No sustituir la variable compartida ni
   seleccionar Production. El traspaso automático de credenciales había sido
   bloqueado según el documento de continuación; no se reintentó por otra vía.
2. **Recuperar respuestas fallidas**. Si Brain falla después de guardar el mensaje
   entrante, el reintento se reconoce como duplicado y no vuelve a generar respuesta.
   Esto se reproduce como TODO. Hace falta estado de procesamiento/entrega y
   reclamación atómica; reintentar indiscriminadamente puede duplicar envíos
   aceptados por un proveedor cuyo resultado no se haya podido persistir.
3. **Identificador ausente**. Definir rechazo o identidad idempotente segura antes
   de permitir respuestas sin trazabilidad CRM.
4. **QA privado**. La rama Neon contiene datos heredados reales. Mantener Preview
   protegido; no usarlo como demostración pública. No borrar ni publicar esos datos.
5. **Verificación real pendiente**. Tras la configuración segura, reconstruir solo
   Preview y comprobar la conexión efectiva y el bloqueo de todas las salidas.
   Después ejecutar las pruebas reales aisladas. No redirigir el webhook activo
   de Meta ni habilitar comunicaciones reales para probar.
